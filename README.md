# 💰 Expense Manager
### Track Expenses. Manage Budgets. Achieve Saving Goals.

Expense Manager is a responsive web application designed to help users manage their daily expenses, monitor their monthly budget, track spending history and set personal saving goals.

## ✨ Features

### 👤 User Profile & Budget Setup
- Create a personal profile.
- Enter your name.
- Set a monthly budget.
- Select your preferred currency.

### 💸 Add Expense
- Add daily expenses through a form.
- Enter expense name and amount.
- Select payment methods:
  - UPI
  - Cash
  - Net Banking
- Save expense records directly into the database.

### 📋 Transaction History
- View all recorded expenses in a history table.
- Automatically record transaction dates.
- Retrieve saved transactions from the database.

### 📊 Expense Reports
- View category-wise expense reports.
- Understand spending patterns.
- Monitor where your money is being spent.

### 🎯 Saving Goals
- Create personal saving goals.
- Set a target saving amount.
- Track how much you have saved.
- Monitor your progress towards financial goals.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL

## 🗄️ Database

- MySQL database for storing user and expense information.
- PHP database connectivity.
- Local development environment using XAMPP.

## 📱 Responsive Design

The application is designed to provide a user-friendly experience across different screen sizes.

## 🚀 How to Run Locally

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin.
5. Create and import the project database.
6. Configure the database connection in the PHP file.
7. Open the project in your browser:

   http://localhost/expense-manager/
